# Data Science Projects

This repository contains Data Science and Machine Learning projects built using Python and Scikit-learn for my CodSoft Internship. The projects focus on data preprocessing, exploratory data analysis, model training, and evaluation using real-world datasets.

## Projects Included

### 1. Titanic Survival Prediction

A classification project that predicts whether a passenger survived the Titanic disaster based on features such as age, gender, class, and fare.

Key Concepts:

* Data Cleaning
* Feature Engineering
* Classification Algorithms
* Model Evaluation

### 2. Movie Rating Prediction

A regression-based Machine Learning project used to predict movie ratings from dataset features.

Key Concepts:

* Data Visualization
* Regression Models
* Feature Selection
* Predictive Analysis

### 3. Iris Flower Classification

A classification project that identifies iris flower species using petal and sepal measurements.

Key Concepts:

* Classification Models
* Exploratory Data Analysis
* Model Training
* Accuracy Evaluation

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Purpose

These projects were developed as part of my learning journey in Machine Learning and Data Science during my CodSoft Internship to strengthen practical knowledge of data analysis, preprocessing, and predictive modeling.
